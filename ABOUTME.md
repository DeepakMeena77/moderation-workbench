## Why this problem

Moderation is a place where AI is genuinely useful and genuinely risky, so I wanted to build one where the line is
enforced rather than promised: the model only recommends, a database trigger keeps visibility changes human, and
every claim the model makes about evidence is checked against the text. Policy versioning, appeals to a different
moderator and a tamper-evident audit trail made it a real systems problem, not only a prompt.

## What I would build next

- A stored checkpoint for the audit chain, so verification stays fast as the trail grows and truncation from the
  end is detected too.
- Notifications for authors when a decision or appeal outcome lands, and per-moderator workload in the metrics.
